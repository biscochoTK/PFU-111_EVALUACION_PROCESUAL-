# SISTEMA DE INVENTARIO - DISTRIBUIDORA

## 1. Descripcion del proyecto

El Sistema de Inventario para una Distribuidora es un programa desarrollado en Python que permite administrar los productos de una empresa de manera organizada.

El sistema permite registrar, consultar y actualizar productos, facilitando el control del inventario.

## 2. Objetivo

Desarrollar un sistema de inventario utilizando Python, aplicando funciones, listas, diccionarios, estructuras condicionales, ciclos y almacenamiento de informacion mediante archivos JSON.

## 3. Tecnologias utilizadas

- Python
- Visual Studio Code
- CMD (Simbolo del sistema)
- Git
- GitHub
- JSON

## 4. Funcionalidades

El sistema contempla las siguientes funcionalidades:

1. Registrar productos.
2. Consultar productos.
3. Actualizar productos.
4. Guardar informacion del inventario.
5. Recuperar informacion almacenada.
6. Validar los datos ingresados.

## 5. Informacion de los productos

Cada producto contiene los siguientes datos:

- Codigo
- Nombre
- Precio
- Cantidad disponible

## 6. Estructura del proyecto

Inventario_Distribuidora/
|
|-- main.py
|-- productos.json
|-- README.md
|-- .gitignore

## 7. Requisitos para ejecutar

- Tener Python instalado.
- Tener Visual Studio Code o una terminal CMD.
- Tener los archivos del proyecto.

## 8. Como ejecutar el programa

1. Abrir la carpeta del proyecto.
2. Abrir la terminal.
3. Ejecutar el siguiente comando:

python main.py

## 9. Almacenamiento de datos

El archivo productos.json se utilizara para almacenar la informacion de los productos en formato JSON, permitiendo conservar los datos del inventario.
